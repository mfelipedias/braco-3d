Pegada automática: o braço planeja a trajetória, pega a vidraria e a levanta.

    Pegada manual Posicione a garra em volta da vidraria (corpo, gargalo, tampa, base…) e feche a garra para pegar. Abra a garra para soltar a peça sobre a mesa.

    Como usar

    Vista
    Arraste para girar, botão direito (ou dois dedos) para deslocar, role para aproximar.
    Juntas
    Mova os controles deslizantes ou use o teclado: A/D base, S/W ombro, F/R cotovelo, G/T punho, Q/E rotação, Z/X fecha/abre a garra. As teclas podem ser trocadas na aba Teclado.
    Vidrarias
    Use “Pegar” para uma pegada automática, ou feche a garra em volta de uma vidraria para pegá-la à mão. Abra a garra sobre a mesa para soltar.
    Gestos
    Ligue a câmera e faça os gestos treinados no Teachable Machine. A câmera só funciona em HTTPS ou em localhost. Para usar um modelo seu, veja “Como treinar um modelo novo” no painel Gestos.

    Treinar gestos

    O reconhecimento usa um modelo de imagem do Google Teachable Machine. Você pode treinar o seu e testá-lo aqui sem instalar nada.

    1. Abra um projeto de imagem. No Teachable Machine escolha Projeto de imagem → Modelo de imagem padrão. Para melhorar um projeto existente, use ☰ → Abrir projeto do arquivo e escolha o arquivo .tm.
    2. Crie uma classe por gesto, com estes nomes exatos (maiúsculas e acentos contam):
      • Paradonada
      • Abrirabre a garra
      • Fecharfecha a garra
      • Esquerdagira a base
      • Direitagira a base
      • Subirgarra sobe
      • Descergarra desce
      Classes com outros nomes também funcionam: elas chegam sem ação e você escolhe a ação de cada uma no painel Gestos.
    3. Grave as amostras pela webcam, de 150 a 300 por classe. Varie distância, posição da mão e iluminação. Na classe Parado, grave só você, sem a mão, e também o fundo vazio.
    4. Treine com Treinar modelo e confira na prévia se cada gesto passa de 85% de confiança.
    5. Exporte: Exportar modelo → TensorFlow.js → Fazer download → Baixar meu modelo. Você recebe um .zip.
    6. Teste aqui: no painel Gestos clique em Carregar modelo… e escolha o .zip (ou arraste o arquivo até o painel). Depois ligue a câmera.
    7. Guarde o projeto com ☰ → Salvar projeto no arquivo para poder retreinar depois.

    O modelo carregado fica só neste navegador: ele não é enviado para o servidor e some ao recarregar a página. O arquivo .tm é o projeto com as fotos de treino e não funciona direto aqui; exporte o modelo antes.
