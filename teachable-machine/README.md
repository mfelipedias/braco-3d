# Projeto do Teachable Machine

Coloque aqui o arquivo de projeto `.tm` (ex.: `gestos-braco.tm`) para retreinar o modelo de gestos.

O `.tm` contém as fotos de treino tiradas pela webcam e por isso **não vai para o Git**
(veja `.gitignore`). Guarde uma cópia em local seguro.

Passo a passo de treino e exportação: [docs/treinar-gestos.md](../docs/treinar-gestos.md).
